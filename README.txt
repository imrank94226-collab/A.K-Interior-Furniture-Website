HOW THE ENQUIRY FORM WORKS
- Customer fills name, phone, project/meeting address and optional details.
- The website opens WhatsApp to +91 77987 37194 with the enquiry pre-filled.
- Customer must tap Send in WhatsApp. A website cannot silently send a WhatsApp message from the customer's account.

EMAIL
- Email delivery is not configured yet because the business email address has not been provided. Once you share the email, the website can be connected to an email form service or backend. Do not put email passwords in the HTML file.

PUBLISH ON GITHUB PAGES
1. Open your repository on GitHub.
2. Upload index.html to the repository root (not inside an extra nested folder).
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish and open the displayed site link.

CUSTOMISATION
- The current interior illustrations are CSS-made placeholders, not real project photos. Replace them with your own project/furniture photos when available.
